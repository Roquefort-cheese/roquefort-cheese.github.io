## Найденные проблемы

### 1. «Назначить неправильно» имел две конкурирующие машины
`mechanics.js` и `ritual.js` одновременно слушали одну кнопку и меняли состояние одной сцены. Это порождало расхождение между визуалом, журналом событий и автоматом состояний.

**Исправление:** `mechanics.js` удалён из публичной логики и из layout; ритуал теперь управляется одним `ritual.js`.

### 2. Ритуал не объяснял событие
Старая версия в основном меняла фазу/градиент/текст, но не формулировала человеческую сцену: кому назначено, когда это происходит, зачем, где именно нелепость и чем всё закончилось.

**Исправление:** введён «лист назначения» с полями `КОМУ / КОГДА / ЗАЧЕМ / ГДЕ ГРОТЕСК / ОБЪЕКТ / ДОЛЖНОСТЬ`, затем явная последовательность `проект → подтверждение → вступление в силу → пошло не так → цифровой сбой → остаток`.

### 3. Первый клик сразу совершал назначение
Старая логика выбирала кандидатуру и в тот же обработчик могла сразу коммитить её.

**Исправление:** первый клик только предлагает нелепое назначение; второй подтверждает его. После подтверждения действие становится необратимым до автоматического сброса.

### 4. Мудрец Целибата показывался заглушкой
На главной использовался `thumbnail` SVG вместо реального портрета.

**Исправление:** главная использует исходный `assets/img/mudrets-tselibata.webp`; контент-гейт сохранён только на детальной странице как слой предупреждения.

### 5. В проекте остался мёртвый слой Dissonance Console
После удаления старой механики CSS всё ещё содержал селекторы `.dissonance-console`.

**Исправление:** удалены эти селекторы из kinetic-слоя.

### 6. В коде оставалась старая визуальная модель `.phase-stage`
Она не используется новой ритуальной сценой и остаётся техническим хвостом предыдущей итерации. Она не участвует в текущем DOM и не влияет на новый ритуал.

**Статус:** оставлена как совместимый legacy-слой в этой сборке, чтобы не менять unrelated CSS без необходимости.

## Архитектурный итог

Система «Назначить неправильно» теперь соответствует идее неправильной функции из канона: бытовой предмет сохраняет своё происхождение, получает временную должность, должность создаёт проблему, проблема возвращается в бытовой остаток. Это ближе к связке «неправильное назначение → перформанс → титул → перегрев → линолеум → новая причина».
