# Протокол 418

Статический портал общажного гностического реализма. Источник разметки — `scripts/build.mjs`, контент хранится в `content/`, готовая публичная версия — в `dist/`.

## Сборка и проверка

```sh
npm test
```

Команда заново генерирует главную, архив, Бюро, Канонизатор и 115 страниц работ, затем проверяет ссылки, обязательную структуру HTML, защиту удержанного медиа, наличие всех 105 улик, отсутствие приватных данных и синхронность `dist/` с исходниками.

Для публикации используется только каталог `dist/`.

## Основные адреса

- `/` — Мембрана и ритуал неправильного назначения.
- `/works/` — 105-страничный линолеумный архив и канонические работы.
- `/overheat/` — Канонизатор 418: документ → абсурд → пафос → сбой → остаток.
- `/protocol/` — законы, грамматика и редакционный суд.

## Управление

В архиве клавиша `W` выбирает свидетеля, `R` включает или отменяет разброс, `G` вызывает общий глитч, `Escape` возвращает нейтральный режим. Горячие клавиши отключены во время ввода в поля и работы с кнопками.

В Канонизаторе каждый эффект запускается отдельным нажатием. Состояние короткого журнала хранится только в `sessionStorage`. Старый игровой код ↑ ↑ ↓ ↓ ← → ← → B A оставлен как пасхалка протокола созревания.

## Публичность данных

`content/private/consent-ledger.json` используется только как локальный редакционный реестр и не копируется в `dist/`. Медиа с `contentNotice` не выводится на главной или в витрине без предусмотренного шлюза.
