# Протокол 418. Линолеумное небо — расширенный MVP

Статический сайт, собранный из `content/*.json` в `scripts/build.mjs` по ТЗ
(`Protokol_418_TZ_Karta_Proekta.md`). Три статических маршрута плюс
генерируемые страницы работ — без фреймворков, без сборщиков, только
Node.js на этапе сборки и ванильный JS в браузере.

## Что добавлено в эту версию

В Линолеумный архив подключён полный визуальный корпус из 105 страниц PDF
«общага — сюрреализм». Каждая страница сохранена отдельным WebP-материалом,
имеет собственный URL `/works/corpus-page-001/` … `/works/corpus-page-105/`
и не требует JavaScript для открытия. Для 10 страниц, где в PDF был доступен
текстовый слой, он также вынесен в доступный текстовый блок и участвует в поиске
архива. Исходный PDF не включён в публичную сборку: его страницы воспроизведены
внутри сайта как визуальные листы корпуса.

## Режим 418.2 — мифоперегрев

Документальный корпус не переписывается по содержанию. Поверх него добавлен отдельный редакционный слой: 105 страниц получают временные титулы, неправильные назначения, фазы, материальные возражения, внутренние мемы и связи Мёбиуса. Это сознательный компенсатор: канонические 45/25/20/10 остаются законом системы, но в архиве абсурд, пафос и цифровой сбой появляются чаще, чем в чистой документации.

На главной и в Бюро отображается отдельный «Компенсатор документальности», а на карточках и страницах работ появляется температурная метка. Ритуал «Назначить неправильно» получил банк глючных служебных сообщений, но GlitchLayer по-прежнему запускается только внутри фазовой машины.

## Запуск локально

Публичная сборка лежит в `dist/`. Она содержит только готовые страницы и
ассеты; приватный редакционный реестр в `content/private/` в экспорт не попадает.
Чтобы посмотреть:

```bash
python3 -m http.server 8000 --directory dist
```

Открыть `http://localhost:8000/`.

## Пересборка после правки контента

```bash
node scripts/build.mjs
node scripts/check-build.mjs
```

Скрипт проверяет `content/works.json`, генерирует страницы и пересобирает
безопасный публичный экспорт `dist/`.

## Структура расширенного корпуса

- 10 исходных редакционных работ Протокола 418.
- 105 страниц исходного визуального корпуса `общага — сюрреализм`.
- 115 записей в `content/works.json`.
- 115 страниц работ в публичной сборке.
- 105 архивных WebP-листов в `assets/img/corpus/`.

Согласие на публикацию изображённых людей предоставлено заказчиком проекта;
публичная сборка не публикует внутренний реестр согласий.
